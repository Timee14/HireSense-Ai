Explainable Rationales

Background & Core Problem

  • Rapid digital recruitment volume has led to hundreds of resumes per job posting, overwhelming HR teams.
  • Traditional Applicant Tracking Systems (ATS) rely on exact keyword string queries, resulting in rigid, binary filtering.
  • HireSense AI introduces an end-to-end multi-vector parsing & candidate screening platform designed to eliminate keyword inflexibility.

System Innovations

  • PyMuPDF Stream Parser: Extracts document text while preserving multi-column reading order.
  • 64-Dim Dense Embeddings: Evaluates true semantic context in continuous vector space.
  • Dual-Portal Experience: Provides candidate ATS score feedback and recruiter auto-ranked pipelines.

Slide 03 2. Motivation & Problem Statement
❌ Industry Challenges (Problem Statement)
  • Recruiter Fatigue: Over 250+ applications per position make manual review unmanageable.
  • High False Rejection (~75%): Legacy ATS filters disqualify qualified applicants due to layout formatting or synonymous terms.
  • The Candidate 'Black Hole': Job seekers receive no transparent feedback on rejection causes.
  • Keyword Stuffing Exploits: Unqualified candidates manipulate boolean ATS parsers.
✓ Project Motivation & Solution
  • Objective Evaluation: Evaluate true technical alignment using dense 64-dimensional vector embeddings.
  • Candidate Transparency: Provide interactive category sub-scores and market skill gap advice.
  • Explainable AI Rationales: Generate 2-3 sentence plain-English justifications for recruiters.
  • Sub-50ms Scalability: Auto-rank thousands of candidate profiles instantaneously.

Slide 04 3. Primary Objectives
  • Objective 1 (PyMuPDF Text Parser): Develop a high-performance text extraction engine capable of converting unstructured PDF/DOCX resumes into standardized JSON schemas.
  • Objective 2 (Dense Vector Search): Construct a 64-dimensional embedding vector pipeline and cosine distance similarity search operating in sub-50 milliseconds.
  • Objective 3 (5-Dimensional Scoring Engine): Formulate a dynamic match algorithm balancing Required Skills (35%), Vector Distance (25%), Seniority (20%), Projects (10%), and Education (10%).
  • Objective 4 (Explainable AI Rationales): Implement an explanation generator providing clear, 2-3 sentence hiring justifications for candidates and recruiters.
  • Objective 5 (Ultra-Glassmorphic UI): Build an enterprise-grade React 18 + TypeScript SPA with Tailwind CSS for candidate ATS scoring and recruiter auto-ranked pipelines.

Slide 07 6. Dataset Preprocessing Pipeline
  • Step 1 (PyMuPDF Stream Parsing): Extracts raw text streams page-by-page from PDF files using fitz, preserving reading order.
  • Step 2 (Text Cleaning & Noise Stripping): Removes control characters, irregular line breaks, bullet artifacts, and header/footer noise.
  • Step 3 (Section Entity Segmentation): Parses clean text into logical blocks: Skills, Work Experience, Education, Projects, Certifications.
  • Step 4 (Skill Taxonomy Normalization): Normalizes skill synonyms (e.g. 'JS' -> 'JavaScript', 'Py' -> 'Python') against reference taxonomy.
  • Step 5 (Vector Space Encoding): Converts candidate & job text blocks into normalized 64-dimensional dense numerical vector arrays.
