# Automatic GitHub Contribution & Immediate Push Rule

Whenever any updates, modifications, tweaks, bug fixes, refactoring, documentation updates, or feature additions are completed in this repository:
1. **Always automatically stage all modified and newly created files** (`git add .`).
2. **Commit immediately** with a concise, descriptive, and meaningful commit message (e.g. `feat: ...`, `fix: ...`, `refactor: ...`, `style: ...`, `docs: ...`).
3. **Push immediately** directly to `origin main` (or the active upstream branch) on GitHub.
4. Perform this commit and push automatically without waiting to be prompted, ensuring every single task and daily activity directly increases GitHub contribution activity and streak.
